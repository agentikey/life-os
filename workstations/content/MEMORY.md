# Content Memory

Content memory lives in the LifeOS DB under scope **`ws:content`**.

```
../../memory/mem list --scope ws:content          # browse
../../memory/mem search "<keywords>" --scope ws:content
../../memory/mem add --scope ws:content --type contact --title "..." --body "..."
```

See the root [`MEMORY.md`](../../MEMORY.md) for the full command reference.
