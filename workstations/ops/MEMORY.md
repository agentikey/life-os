# Ops Memory

Ops memory lives in the LifeOS DB under scope **`ws:ops`**.

```
../../memory/mem list --scope ws:ops              # browse
../../memory/mem search "<keywords>" --scope ws:ops
../../memory/mem add --scope ws:ops --type note --title "..." --body "..."
```

See the root [`MEMORY.md`](../../MEMORY.md) for the full command reference.
