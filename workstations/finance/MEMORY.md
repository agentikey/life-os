# Finance Memory

Finance memory lives in the LifeOS DB under scope **`ws:finance`**.

```
../../memory/mem list --scope ws:finance          # browse
../../memory/mem search "<keywords>" --scope ws:finance
../../memory/mem add --scope ws:finance --type decision --title "..." --body "..."
```

See the root [`MEMORY.md`](../../MEMORY.md) for the full command reference.
